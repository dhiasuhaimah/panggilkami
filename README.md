# 📦 PanggilKami

> Teman Andalan Saat Mager Melanda. Kalau kamu mager, biar kami yang gerak.

PanggilKami adalah layanan jasa on-demand untuk anak kos & mahasiswa di **Sukoharjo - Solo**. Fokus kami: bantu titip belanja, antar barang, antar jemput, sampai bersih-bersih kos.

### 🚀 Layanan Utama

- **🛒 Titip & Antar Apa Saja** - Belanja, ambil paket, beli obat, beli makan. Ada foto struk.
- **🏍️ Antar Jemput** - Ke kampus, stasiun, pulang malam. Cepat & aman.
- **🧹 Bersih Kos / Jam** - Sapu, pel, beresin baju, WC. Mulai **20k / jam**.

### ✨ Kenapa Pilih Kami?

✅ Respon Cepat via WhatsApp
✅ Tim Lokal Sukoharjo - Solo (Bukan aplikasi ribet)
✅ Harga Jujur & Transparan
✅ Bayar di tempat bisa

### 📲 Cara Order

Klik WhatsApp di website -> Chat butuh apa -> Tim jalan -> Beres.

### 🛠️ Tech Stack

`Next.js` `Tailwind CSS` `WhatsApp API`
